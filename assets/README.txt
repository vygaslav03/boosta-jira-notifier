=== Boosta Jira Notifier Custom Audio Assets ===

By default, Boosta Jira Notifier uses a Web Audio synthesized anime girl voice chime ("Notice me Senpai / Kyaa~").

If you want to use a specific custom anime voice MP3 file:
1. Place your MP3 file in this folder and name it: `anime_girl.mp3`
2. Or name it: `notice.mp3`
3. The extension will automatically play your custom MP3 file on incoming notifications!
